# 放入路由器 LAN 抓包

1. 在路由器管理页选择 LAN 或 LAN bridge 接口，在 NAT 前抓包；不要选择 WAN。
2. 先抓 60 秒，保留需要调查的正常业务活动。过滤条件留空，文件大小上限应足够覆盖这段时间。
3. 停止抓包，导出 `.pcap`、`.pcapng` 或 `.cap`，复制到本目录。不要放入尚在写入的文件。
4. 在项目目录运行 `analyze.bat`，自动选择本目录中修改时间最新的非示例抓包。
5. 若要避免选错文件，可拖动抓包到 `analyze.bat`，或运行 `analyze.bat "完整文件路径" --open`。

配置文件 `analysis_config.json` 默认内网为 `192.168.110.0/24`。有公网 IPv6 时，填写路由器 LAN 的实际 IPv6 前缀，或用 `--net6` 指定；不能用远端服务器前缀代替。

本目录无真实文件时程序会明确提示，不会自动分析示例。来源标签是用户声明，并不证明采集位置、完整性或是否漏包。不要把本机 WLAN 抓包解释为整个局域网。
